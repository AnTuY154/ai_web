# Shop Hoa Tươi Hồng Hạnh Flower

Project Next.js độc lập cho cửa hàng Hoa tươi tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/33-shop-hoa-tuoi-hong-hanh-flower-hung

Build tĩnh:

    npm run build --workspace sites/33-shop-hoa-tuoi-hong-hanh-flower-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
