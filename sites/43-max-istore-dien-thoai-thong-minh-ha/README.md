# Max iStore ( Điện Thoại Thông Minh )

Project Next.js độc lập cho cửa hàng điện thoại di động tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/43-max-istore-dien-thoai-thong-minh-ha

Build tĩnh:

    npm run build --workspace sites/43-max-istore-dien-thoai-thong-minh-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
