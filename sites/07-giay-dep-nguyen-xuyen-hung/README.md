# Cửa Hàng Giày Dép Nguyện Xuyến

Project Next.js độc lập cho cửa hàng Giày dép tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/07-giay-dep-nguyen-xuyen-hung

Build tĩnh:

    npm run build --workspace sites/07-giay-dep-nguyen-xuyen-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
