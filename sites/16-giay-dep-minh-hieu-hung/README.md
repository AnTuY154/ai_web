# GIẦY DÉP MINH HIẾU

Project Next.js độc lập cho cửa hàng Giày dép tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/16-giay-dep-minh-hieu-hung

Build tĩnh:

    npm run build --workspace sites/16-giay-dep-minh-hieu-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
