# Cửa Hàng Đồ Chơi Trẻ Em Hiểu Khánh

Project Next.js độc lập cho cửa hàng Đồ chơi trẻ em tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/10-do-choi-tre-em-hieu-khanh-bac

Build tĩnh:

    npm run build --workspace sites/10-do-choi-tre-em-hieu-khanh-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
