# Họa Phẩm Hoàng Quân

Project Next.js độc lập cho cửa hàng Họa phẩm tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/18-hoa-pham-hoang-quan-ha

Build tĩnh:

    npm run build --workspace sites/18-hoa-pham-hoang-quan-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
