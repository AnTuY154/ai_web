# Đồ chơi xe Tự Decal Bắc Ninh

Project Next.js độc lập cho cửa hàng Phụ kiện ô tô/xe máy tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/09-do-choi-xe-tu-decal-bac-ninh-bac

Build tĩnh:

    npm run build --workspace sites/09-do-choi-xe-tu-decal-bac-ninh-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
