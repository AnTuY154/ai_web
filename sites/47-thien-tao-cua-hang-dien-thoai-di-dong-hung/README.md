# Thiện Táo - Cửa hàng điện thoại di động

Project Next.js độc lập cho cửa hàng điện thoại di động tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/47-thien-tao-cua-hang-dien-thoai-di-dong-hung

Build tĩnh:

    npm run build --workspace sites/47-thien-tao-cua-hang-dien-thoai-di-dong-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
