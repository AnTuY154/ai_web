# Shop Trang Phục Thể Thao Nam Sport

Project Next.js độc lập cho cửa hàng Thể thao tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/31-shop-trang-phuc-the-thao-nam-sport-bac

Build tĩnh:

    npm run build --workspace sites/31-shop-trang-phuc-the-thao-nam-sport-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
