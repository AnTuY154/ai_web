# Hạnh Shop - Gói quà nghệ thuật

Project Next.js độc lập cho cửa hàng quà tặng tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/50-hanh-shop-goi-qua-nghe-thuat-ha

Build tĩnh:

    npm run build --workspace sites/50-hanh-shop-goi-qua-nghe-thuat-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
