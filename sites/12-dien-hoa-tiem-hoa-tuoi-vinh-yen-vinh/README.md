# Điện hoa - Tiệm hoa tươi Vĩnh Yên

Project Next.js độc lập cho cửa hàng Hoa tươi tại Vĩnh Phúc (khu vực cũ).

Chạy từ thư mục gốc:

    npm run dev --workspace sites/12-dien-hoa-tiem-hoa-tuoi-vinh-yen-vinh

Build tĩnh:

    npm run build --workspace sites/12-dien-hoa-tiem-hoa-tuoi-vinh-yen-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
