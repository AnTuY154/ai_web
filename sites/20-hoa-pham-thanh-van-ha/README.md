# Họa Phẩm Thanh Vân

Project Next.js độc lập cho cửa hàng Họa phẩm tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/20-hoa-pham-thanh-van-ha

Build tĩnh:

    npm run build --workspace sites/20-hoa-pham-thanh-van-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
