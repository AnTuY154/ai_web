# Cửa Hàng Điện Thoại Di Động Đoài Apple

Project Next.js độc lập cho cửa hàng Điện thoại tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/15-dien-thoai-di-dong-doai-apple-hung

Build tĩnh:

    npm run build --workspace sites/15-dien-thoai-di-dong-doai-apple-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
