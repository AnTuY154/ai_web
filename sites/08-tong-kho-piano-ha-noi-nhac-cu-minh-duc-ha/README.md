# Tổng Kho Piano Hà Nội - Nhạc Cụ Minh Đức

Project Next.js độc lập cho cửa hàng Nhạc cụ tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/08-tong-kho-piano-ha-noi-nhac-cu-minh-duc-ha

Build tĩnh:

    npm run build --workspace sites/08-tong-kho-piano-ha-noi-nhac-cu-minh-duc-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
