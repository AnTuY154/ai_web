# Cửa Hàng Giày Dép Phong Thúy

Project Next.js độc lập cho cửa hàng giày dép tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/40-giay-dep-phong-thuy-ha

Build tĩnh:

    npm run build --workspace sites/40-giay-dep-phong-thuy-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
