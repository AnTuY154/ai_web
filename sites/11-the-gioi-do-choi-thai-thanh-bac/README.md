# Cửa Hàng Thế Giới Đồ Chơi Thái Thành

Project Next.js độc lập cho cửa hàng Đồ chơi trẻ em tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/11-the-gioi-do-choi-thai-thanh-bac

Build tĩnh:

    npm run build --workspace sites/11-the-gioi-do-choi-thai-thanh-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
