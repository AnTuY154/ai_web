# Hệ thống cửa hàng điện thoại di động TĐ PHONE | EMPIRE

Project Next.js độc lập cho cửa hàng bán đồ điện tử tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/46-he-thong-cua-hang-dien-thoai-di-dong-td-ph-hung

Build tĩnh:

    npm run build --workspace sites/46-he-thong-cua-hang-dien-thoai-di-dong-td-ph-hung
