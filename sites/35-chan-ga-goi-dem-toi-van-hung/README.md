# Chăn ga gối đệm Tới Vân

Project Next.js độc lập cho cửa hàng Chăn ga gối đệm tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/35-chan-ga-goi-dem-toi-van-hung

Build tĩnh:

    npm run build --workspace sites/35-chan-ga-goi-dem-toi-van-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
