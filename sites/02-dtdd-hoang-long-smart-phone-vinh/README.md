# Cửa Hàng ĐTDĐ Hoàng Long Smart Phone

Project Next.js độc lập cho cửa hàng Điện thoại tại Vĩnh Phúc (khu vực cũ).

Chạy từ thư mục gốc:

    npm run dev --workspace sites/02-dtdd-hoang-long-smart-phone-vinh

Build tĩnh:

    npm run build --workspace sites/02-dtdd-hoang-long-smart-phone-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
