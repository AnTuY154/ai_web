# Tấn Con Shop Thời Trang Nam

Project Next.js độc lập cho cửa hàng Thời trang nam tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/06-tan-con-shop-thoi-trang-nam-bac

Build tĩnh:

    npm run build --workspace sites/06-tan-con-shop-thoi-trang-nam-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
