# Công ty TNHH BGHOME Chi nhánh Hưng Yên

Project Next.js độc lập cho cửa hàng Nội thất tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/24-bghome-chi-nhanh-hung-yen-hung

Build tĩnh:

    npm run build --workspace sites/24-bghome-chi-nhanh-hung-yen-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
