# Cửa Hàng Thú Cưng Petty Bell

Project Next.js độc lập cho cửa hàng Thú cưng tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/28-thu-cung-petty-bell-bac

Build tĩnh:

    npm run build --workspace sites/28-thu-cung-petty-bell-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
