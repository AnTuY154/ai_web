# Click Phone - Vĩnh Yên

Project Next.js độc lập cho cửa hàng Điện thoại tại Vĩnh Phúc (khu vực cũ).

Chạy từ thư mục gốc:

    npm run dev --workspace sites/03-click-phone-vinh-yen-vinh

Build tĩnh:

    npm run build --workspace sites/03-click-phone-vinh-yen-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
