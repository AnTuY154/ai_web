# Giầy Dép Minh Phát (Thơm Báu)

Project Next.js độc lập cho cửa hàng Giày dép tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/23-giay-dep-minh-phat-thom-bau-hung

Build tĩnh:

    npm run build --workspace sites/23-giay-dep-minh-phat-thom-bau-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
