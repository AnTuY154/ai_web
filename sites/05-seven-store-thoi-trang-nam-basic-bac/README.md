# SEVEN STORE - Thời Trang Nam Basic

Project Next.js độc lập cho cửa hàng Thời trang nam tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/05-seven-store-thoi-trang-nam-basic-bac

Build tĩnh:

    npm run build --workspace sites/05-seven-store-thoi-trang-nam-basic-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
