# Đại Lý Xe Đạp Thống Nhất Anh Nghĩa

Project Next.js độc lập cho cửa hàng Xe đạp tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/30-dai-ly-xe-dap-thong-nhat-anh-nghia-bac

Build tĩnh:

    npm run build --workspace sites/30-dai-ly-xe-dap-thong-nhat-anh-nghia-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
