# Nu-Art Shop - Thế giới họa cụ mới

Project Next.js độc lập cho cửa hàng Họa phẩm tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/25-nu-art-shop-the-gioi-hoa-cu-moi-ha

Build tĩnh:

    npm run build --workspace sites/25-nu-art-shop-the-gioi-hoa-cu-moi-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
