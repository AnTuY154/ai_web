# Xe Điện Nhật Minh

Project Next.js độc lập cho cửa hàng Xe đạp/xe điện tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/29-xe-dien-nhat-minh-bac

Build tĩnh:

    npm run build --workspace sites/29-xe-dien-nhat-minh-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
