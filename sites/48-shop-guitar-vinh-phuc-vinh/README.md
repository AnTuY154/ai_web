# Shop Guitar Vĩnh Phúc

Project Next.js độc lập cho cửa hàng nhạc cụ tại Vĩnh Phúc.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/48-shop-guitar-vinh-phuc-vinh

Build tĩnh:

    npm run build --workspace sites/48-shop-guitar-vinh-phuc-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
