# Cửa hàng Chăn, ga, gối, đệm Yến Đức

Project Next.js độc lập cho cửa hàng Chăn ga gối đệm tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/34-chan-ga-goi-dem-yen-duc-hung

Build tĩnh:

    npm run build --workspace sites/34-chan-ga-goi-dem-yen-duc-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
