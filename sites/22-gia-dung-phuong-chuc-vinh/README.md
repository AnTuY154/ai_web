# Cửa Hàng Gia Dụng Phượng Chúc

Project Next.js độc lập cho cửa hàng Đồ gia dụng tại Vĩnh Phúc (khu vực cũ).

Chạy từ thư mục gốc:

    npm run dev --workspace sites/22-gia-dung-phuong-chuc-vinh

Build tĩnh:

    npm run build --workspace sites/22-gia-dung-phuong-chuc-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
