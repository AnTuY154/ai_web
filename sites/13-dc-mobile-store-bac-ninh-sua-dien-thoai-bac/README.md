# DC Mobile Store Bắc Ninh - Sửa điện thoại

Project Next.js độc lập cho cửa hàng Điện thoại & sửa chữa tại Bắc Ninh.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/13-dc-mobile-store-bac-ninh-sua-dien-thoai-bac

Build tĩnh:

    npm run build --workspace sites/13-dc-mobile-store-bac-ninh-sua-dien-thoai-bac

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
