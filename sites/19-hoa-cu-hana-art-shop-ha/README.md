# Họa cụ Hana art shop

Project Next.js độc lập cho cửa hàng Họa phẩm tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/19-hoa-cu-hana-art-shop-ha

Build tĩnh:

    npm run build --workspace sites/19-hoa-cu-hana-art-shop-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
