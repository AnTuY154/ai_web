# Tiệm hoa nhà mốc - Hoa Tươi Yên Mỹ

Project Next.js độc lập cho cửa hàng Hoa tươi tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/32-tiem-hoa-nha-moc-hoa-tuoi-yen-my-hung

Build tĩnh:

    npm run build --workspace sites/32-tiem-hoa-nha-moc-hoa-tuoi-yen-my-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
