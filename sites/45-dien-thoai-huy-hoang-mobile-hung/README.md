# Cửa Hàng Điện Thoại Huy Hoàng Mobile

Project Next.js độc lập cho cửa hàng điện thoại di động tại Hưng Yên.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/45-dien-thoai-huy-hoang-mobile-hung

Build tĩnh:

    npm run build --workspace sites/45-dien-thoai-huy-hoang-mobile-hung

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
