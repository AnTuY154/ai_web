# Better Shoes - Cửa hàng giày dép và phụ kiện

Project Next.js độc lập cho cửa hàng giày dép tại Hà Nội.

Chạy từ thư mục gốc:

    npm run dev --workspace sites/37-better-shoes-cua-hang-giay-dep-va-phu-ki-ha

Build tĩnh:

    npm run build --workspace sites/37-better-shoes-cua-hang-giay-dep-va-phu-ki-ha

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
