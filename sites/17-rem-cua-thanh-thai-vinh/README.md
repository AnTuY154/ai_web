# Cửa Hàng Rèm Cửa Thành Thái

Project Next.js độc lập cho cửa hàng Rèm cửa tại Vĩnh Phúc (khu vực cũ).

Chạy từ thư mục gốc:

    npm run dev --workspace sites/17-rem-cua-thanh-thai-vinh

Build tĩnh:

    npm run build --workspace sites/17-rem-cua-thanh-thai-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
