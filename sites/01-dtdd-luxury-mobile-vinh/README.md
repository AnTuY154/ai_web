# Cửa Hàng ĐTDĐ Luxury Mobile

Project Next.js độc lập cho cửa hàng Điện thoại tại Vĩnh Phúc (khu vực cũ).

Chạy từ thư mục gốc:

    npm run dev --workspace sites/01-dtdd-luxury-mobile-vinh

Build tĩnh:

    npm run build --workspace sites/01-dtdd-luxury-mobile-vinh

Xem MARKET_RESEARCH.md để đọc nghiên cứu và giả định nội dung.
